# DoFast Totem

Instaladores oficiais do **DoFast Totem** — o aplicativo que transforma um
computador com tela touch e balança no totem de autopesagem do DoFast: abre
sozinho em tela cheia quando o computador liga, lê a balança direto pelo cabo,
mantém a tela acesa e se atualiza sozinho entre um cliente e outro.

➡️ **Baixe sempre pelo painel do DoFast** (Configurações → Operação, no bloco
"Totem de autopesagem"), que aponta para a versão correta para o seu sistema.

As versões aqui publicadas são geradas e assinadas automaticamente pelo
pipeline oficial do DoFast. Este repositório não contém código-fonte.
